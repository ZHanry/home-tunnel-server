# NestLink

The **14.0.0 stable release target** is under implementation and acceptance. Web provides management and in-browser remote control; Windows x64 and Linux x64/ARM64 provide controllers, hosts and tunnel hubs; Android ARM64/x86_64 uses one universal management/controller APK.

Sign in to your own HTTPS server to retrieve connection settings. Remote control requires encrypted direct P2P plus host approval or password verification. Desktop clients manage tunnels independently of remote sessions. Standalone CLI/NAS products and macOS GUI packages are outside the product scope.

See [release scope and upgrade notes](docs/HOMEDESK_RELEASE.md) and [current Web screenshots and provenance](docs/UI_TESTING.md). Captures show the actual 14.0.0 Web interface with local preview fixtures; they do not assert remote media or tunnel runtime acceptance. Installation/configuration identities and the Android release certificate are preserved. Apache-2.0 and AGPL-3.0 apply to their respective source components; corresponding sources and licenses accompany the release.
