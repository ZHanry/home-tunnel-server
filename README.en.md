# Home Tunnel Server

The Home Tunnel API, web console, HTTP traffic gateway and self-hosted Caddy/FRPS deployment.
This repository supports Linux amd64 and arm64. It builds independently of client source trees.

See the [Chinese overview](README.md), [self-hosting guide](docs/SELF_HOSTING.md),
[development checks](CONTRIBUTING.md), [release process](docs/RELEASING.md), and
[project hub](https://github.com/ZHanry/home-tunnel).

The published 5.0.0 deployment baseline and API v1 remain compatible after migration.
The shared desktop/NAS client is in [home-tunnel-client](https://github.com/ZHanry/home-tunnel-client);
the remote management app is in [home-tunnel-android](https://github.com/ZHanry/home-tunnel-android).
